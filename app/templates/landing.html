Install it as an app

Recruit works in any browser, but phones only deliver push notifications to installed apps. It takes about 15 seconds.

Android · Chrome

  1. Open {{ request.url.hostname }} in Chrome
  2. Tap the Install chip that slides up from the bottom — or the install icon at the right of the address bar
  3. No chip? Tap the ⋮ menu at the right end of Chrome's toolbar → Install app

The menu is bottom-right on newer Chrome and top-right on older builds — it moved, so look at the toolbar, not a fixed corner. Samsung Internet: ☰ → Add page to → Home screen.

iPhone · Safari

  1. Open {{ request.url.hostname }} in Safari
  2. Tap Share (the box with an arrow)
  3. Tap Add to Home Screen, then Add

Desktop · Chrome / Edge

  1. Click the install icon at the right end of the address bar
  2. Or ⋮ → Cast, save and share → Install page as app
  3. It opens in its own window

Edge: … → Apps → Install this site as an app.

Last step Open the installed app and tap Turn on notifications.
