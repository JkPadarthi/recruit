Install it as an app

Recruit works in any browser, but phones only deliver push notifications to installed apps. It takes about 15 seconds.

Android · Chrome

  1. Open {{ request.url.hostname }} in Chrome
  2. Tap the ⋮ menu, top-right
  3. Tap Install app or Add to Home screen

iPhone · Safari

  1. Open {{ request.url.hostname }} in Safari
  2. Tap Share (the box with an arrow)
  3. Tap Add to Home Screen, then Add

Desktop · Chrome / Edge

  1. Click the install icon in the address bar
  2. Or ⋮ → Install Recruit
  3. It opens in its own window
Last step Open the installed app and tap Turn on notifications.
